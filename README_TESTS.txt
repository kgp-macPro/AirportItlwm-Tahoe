# Current test instructions

Use the [single maintained benchmark guide](docs/benchmark/README.md). The active driver choices are unchanged AirportItlwm-Tahoe Alpha 2/P8R1 for BE200, AX201, AX210 and AX211, or the specifically named laobamac build 53 as an optional comparison for supported AX201/AX210/AX211 only. No BE200 compatibility is claimed for laobamac.

The guide contains the current r12 tool download, complete setup, wired-server and Wi-Fi-client commands, identity/mode checks, 3×20 versus historical 3×14 protocols, interpretation and result return procedure. The [verified 60-test BE200 report](docs/benchmark/BE200_ALPHA2_VHT160_3X20_20261104.md) uses only its original 3×20 archive.

Historical beta/ZC comparisons and downloads remain in the [1.1.0 Beta release](https://github.com/kgp-macPro/AirportItlwm-Tahoe/releases/tag/v1.1.0-beta.1), the [historical results section](README.md#selected-historical-best-results--original-whole-test-measurements) and the frozen r11/older tool packages. They are not part of the current entry flow.
