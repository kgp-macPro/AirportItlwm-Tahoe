Current complete instructions: docs/benchmark/README.md in the repository or TOOLS/README.md in the extracted r12 package.

After extracting AirportItlwm-Shared-Benchmark-r12.zip into Downloads, run on both Macs:
/bin/bash "$HOME/Downloads/AirportItlwm-Shared-Benchmark-r12/SETUP_AirportItlwm_Benchmark.command"

Wired server (Wi-Fi off, choose actual Ethernet interface):
/bin/bash "$HOME/Desktop/AirportItlwm/TOOLS/AirportItlwm_IPERF3_WIRED_SERVER.sh"

Wi-Fi client, unchanged Alpha 2/P8R1 (choose one matching profile; client prompts for the server IPv4):
CANDIDATE_KEXT="$HOME/Downloads/AirportItlwm-Tahoe-1.2.0-BE200-Alpha-2/AirportItlwm.kext" /bin/bash "$HOME/Desktop/AirportItlwm/TOOLS/AirportItlwm_3x20_PORTABLE_IP_PROMPT.sh" BE200-ALPHA2 mapped

AX201-ALPHA2, AX210-ALPHA2 or AX211-ALPHA2 use the same bundle path with the corresponding profile. Use conventional only for an actual Mode 1 KGP run. Optional laobamac build 53 is for verified AX201/AX210/AX211 only, never BE200; its mode argument declares AppleVTD configuration, not a measured KGP DMA mode. Keep the original result ZIP, including failures.
