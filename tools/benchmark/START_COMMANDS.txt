AirportItlwm-Tahoe 2.0.0 / benchmark tools r13

Full current instructions: https://github.com/kgp-macPro/AirportItlwm-Tahoe/blob/main/docs/benchmark/README.md

Wired Mac: identify its Ethernet interface and verify negotiated 1000Base-T for VHT, 2500Base-T for HE/HE+BF. Never 5000Base-T/10GBase-T for these campaigns.
Server: iperf3 -s -B YOUR_WIRED_SERVER_IPV4 -p 5201

Client example (replace interface, paths and labels for your device):
WIFI_IFACE=en2 DEVICE_LABEL=AX210 CANDIDATE_LABEL=AX210-2.0.0 EXPECTED_MODE=mapped /bin/bash "$HOME/Downloads/AirportItlwm-Tahoe-Benchmark-Tools-r13/AirportItlwm_3x20_PORTABLE_IP_PROMPT.sh" "$HOME/Downloads/AirportItlwm-Tahoe-2.0.0/AirportItlwm.kext"

The server IP is prompted. Standard runner is the VHT starting point. For HE use -itlwmhe and an appropriate extended runner after confirming 2500Base-T. HE+BF additionally uses -itlwmbf. No -novht.
BE200: add BENCHMARK_PROFILE=be200, DEVICE_LABEL=BE200, CANDIDATE_LABEL=BE200-2.0.0. AX201/CNVW uses conventional, not forced mapped. AX211 uses observed runtime mode. New AX201/AX211 HE/BF remains hardware-unvalidated.
Return the full result ZIP. The candidate path is an identity reference to the already loaded bundle, not an installation command.
