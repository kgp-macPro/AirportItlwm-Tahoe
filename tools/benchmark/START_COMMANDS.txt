Current public commands and prerequisites: README.md in this directory.
Central maintained guide: https://github.com/kgp-macPro/AirportItlwm-Tahoe/blob/main/docs/benchmark/README.md

SERVER (run tool setup first on both Macs):
/bin/bash "$HOME/Desktop/AirportItlwm/TOOLS/AirportItlwm_IPERF3_WIRED_SERVER.sh"

CLIENT (matching extracted Alpha 2 bundle, installed/rebooted manually):
CANDIDATE_KEXT="$HOME/Downloads/AirportItlwm-Tahoe-1.2.0-BE200-Alpha-2/AirportItlwm.kext" DEVICE_LABEL=BE200 /bin/bash "$HOME/Desktop/AirportItlwm/TOOLS/AirportItlwm_3x14_PORTABLE_IP_PROMPT.sh" BE200-ALPHA2 mapped

Server prompts for wired interface and binds its current IPv4; client prompts for that IPv4.
No interface/provider names are assumed. No test was executed by preparing these commands.
