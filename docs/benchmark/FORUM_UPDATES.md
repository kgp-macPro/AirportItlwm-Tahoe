# Archived manual forum drafts — not posted

These r11/3×14 drafts are historical. Current instructions use AirportItlwm-Tahoe **2.0.0** and the **r14 instruction package** (unchanged r13 runtime files): see the [maintained benchmark guide](README.md) and [repository README](../../README.md). Do not reuse the historical download, candidate or DMA instructions below as current guidance.

## InsanelyMac

The current 1.2.0 Alpha is now our primary KGP validation candidate for AX201, AX210, AX211 and BE200. BE200 has physical results; AX201/AX210/AX211 owners are invited to validate the shared build. The updated common 3×14 tools provide explicit Alpha profiles, checked device/interface/DMA routing and safe Desktop setup while retaining the original measurement protocol. No Kext was rebuilt for this tool update.

[Current test guide, prerequisites, server/client commands and result submission](https://github.com/kgp-macPro/AirportItlwm-Tahoe/blob/main/docs/benchmark/README.md) · [Complete shared benchmark r11 download](https://github.com/kgp-macPro/AirportItlwm-Tahoe/raw/refs/heads/main/tools/benchmark/releases/AirportItlwm-Shared-Benchmark-r11.zip).

Please run the current tool setup after the older beta setup, which still supplies r7. Frozen ZC builds remain optional references/fallbacks. All supported laobamac 44/47/53 comparisons remain available for AX201/AX210/AX211 ONLY; those external builds do not support BE200. BE200 may optionally compare earlier own BE200 candidates. The KGP Alpha requires Retro-OCLP-CustoMac restored legacy wireless/root patches; the external native control has different prerequisites, and a Kext swap does not remove patches. Return failures and slow campaigns too. Existing forensic captures/attachments remain separate from throughput testing.
