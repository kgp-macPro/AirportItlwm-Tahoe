# 2.0.0 campaign evidence

All values are recomputed from original iperf3 JSON. TCP tables use receiver
sum_received rates, arithmetic means of 3 rounds; sender TCP retransmits remain
separate. Each listed campaign completed 60 tests + one Internet online test.
BE200 P10 and AX210 P10/R9 retain their original UUID/hash, not the new 2.0.0 UUID.
[Campaign index with original archive hashes, mode properties, matrices and raw-file digests](2.0.0-campaigns.json) · [all 660 measurements](2.0.0-measurements.csv).

The [release results asset](https://github.com/kgp-macPro/AirportItlwm-Tahoe/releases/download/v2.0.0/AirportItlwm-Tahoe-2.0.0-Results.zip)
contains original iperf JSON and a reproducible aggregation script. It is a
publicly selected evidence bundle, not a byte-for-byte copy of private whole-
machine capture ZIPs. Source ZIP names/SHA256 and every included raw-file hash
are recorded. Full registries, unrelated boot settings and internal handovers
were not uploaded. 4,166 original file hashes were verified across 11 archives.

Required **new comparison** peer links: VHT 1G, HE/BF 2.5G, never 5/10G. Historical
client archives do not independently measure the negotiated peer Ethernet link;
early and later BE200 runs must not be pooled as a single controlled BF A/B.
Full testbed, caveats and screenshot contexts: [README](../../README.md).
